# metrics-collector

Сервис сбора метрик и алертинга: агент собирает runtime-метрики Go-приложения и отправляет их на сервер, сервер хранит их и отдаёт по HTTP.

Проект по программе учебного трека «Сервер сбора метрик и алертинга» (Яндекс Практикум): развивается по инкрементам, каждый добавляет новую функциональность, а код в репозитории проверяется автотестами трека через GitHub Actions.

## Как это устроено

Проект состоит из двух приложений:

**Агент** (`cmd/agent`) — раз в `pollInterval` собирает метрики из `runtime.MemStats` (Alloc, HeapAlloc, GC и т.д.) плюс счётчик опросов и случайное значение, и раз в `reportInterval` отправляет их на сервер по HTTP.

**Сервер** (`cmd/server`) — принимает метрики, хранит их в памяти (in-memory storage за интерфейсом репозитория) и отдаёт по запросу.

Метрики двух типов:
- `gauge` — значение перезаписывается (например, объём памяти)
- `counter` — значение накапливается (например, число опросов)

## Стек

- **Go 1.25**, роутер — chi
- Логирование — zap (подключено как middleware: логируются запросы и ответы)
- Тесты — testify
- CI — GitHub Actions (автотесты инкрементов + статический анализ)

## Структура

```
cmd/
  agent/         — точка входа агента
  server/        — точка входа сервера
internal/
  agent/         — сбор метрик (collector), хранение, отправка (sender)
  handler/       — HTTP-хендлеры сервера
  service/       — бизнес-логика
  repository/    — in-memory хранилище
  middleware/    — логирование запросов
  model/         — модель метрики
  config/        — конфигурация: флаги + переменные окружения
```

## API сервера

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/update/{type}/{name}/{value}` | Сохранить метрику |
| GET | `/value/{type}/{name}` | Получить значение метрики |
| GET | `/` | HTML-страница со всеми метриками |

## Как запустить

Сервер:

```bash
go run ./cmd/server -a localhost:8080
```

Агент:

```bash
go run ./cmd/agent -a localhost:8080 -p 2 -r 10
```

где `-p` — интервал опроса метрик (сек), `-r` — интервал отправки на сервер (сек). Всё то же самое настраивается переменными окружения `ADDRESS`, `POLL_INTERVAL`, `REPORT_INTERVAL` — они имеют приоритет над флагами.

Тесты:

```bash
go test ./...
```
